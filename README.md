# 심화반 프로젝트

## 📌 주제 및 선정배경

책 표지 자동 요약기

도서관에서는 다양한 책을 접할 수 있지만, 책 표지만으로는 어떤 책을 읽어야 할지 결정하기 어렵다 . 따라서 GPT 기반 이미지 분석 기능을 활용하여 책 표지에서 주요 정보를 자동으로 추출하고, 간단한 요약 및 카테고리를 생성하는 시스템을 개발하고자 한다. 이를 통해 독서 관리의 효율성을 높이고, 개인 맞춤형 독서 데이터베이스 구축에 기여할 수 있다.

## 🎯 목표

본 프로젝트의 목표는 사용자가 촬영한 책 표지 이미지를 자동으로 인식하고 요약하여 독서 기록을 효율적으로 관리할 수 있는 시스템을 개발하는 것이다. 구체적으로는 GPT 이미지 분석 기능을 활용하여 책 표지에서 제목, 저자, 출판사 등의 기본 정보를 추출하고 간단한 요약과 태그를 생성한다.

이를 통해 사용자는 장르, 저자, 키워드 등의 조건으로 독서 내역을 손쉽게 검색하고 분류할 수 있으며, 자동으로 축적된 데이터를 활용하여 개인 맞춤형 독서 관리 및 추천 서비스로 확장할 수 있다.

## 🧩 사용 기술

- Python, PyQt5
- OpenAI API
- SQLite3
- dotenv (.env 환경변수)

## 🔁 전체 흐름

1. 이미지 업로드
2. 프롬프트 입력
3. GPT로 분류/설명 요청
4. 결과 출력 및 DB 저장
5. 검색 기능으로 레이블 탐색

## 🔧 시스템 구성도 (Architecture)

```
[ 사용자 ]
↓
[ PyQt5 GUI ]
↓
┌───────────────┐
│ 책 표지 이미지 │
│ + 프롬프트 │
└───────────────┘
↓
[ GPT API 호출 ]
↓
[ 결과 출력 및 저장 ] → [ SQLite DB ]

검색 / 조회 흐름
[ 사용자 검색 질의 ]
↓
[ SQLite DB 조회 ]
↓
[ 검색 결과 출력 ] → [ PyQt5 GUI ]

```

## 📁 디렉토리 구조

```
project/
├── gui/
│   └── main_app.py          # PyQt5 GUI 메인 애플리케이션
├── api/
│   └── openai_api.py        # GPT API 호출 및 이미지 분석 기능
├── db/
│   └── book_log.db          # 책 정보 저장용 SQLite DB
├── utils/
│   └── file_handler.py      # 이미지 파일 처리, 데이터 입출력 유틸리티
├── data/
│   ├── covers/              # 책 표지 이미지
│   └── exports/             # CSV/Excel 출력
├── main.py                  # 전체 실행 스크립트
├── .env                     # API 키 등 환경변수
└── requirements.txt         # 프로젝트 패키지 의존성
```

## 📷 예시 시나리오

- 사용자가 책을 읽거나 구매 후 책 표지 이미지를 촬영
- GPT 이미지 분석 기능이 책 표지 이미지를 인식 → 제목, 저자, 출판사, 장르, 표지 특징 등 텍스트 및 디자인 정보 추출
- 추출된 정보를 기반으로 책 제목, 저자, 출판사, 장르, 분위기 태그 자동 분류
- 각 항목을 카테고리별 태그로 자동 정리 (예: 소설, 자기계발, 역사, 그림책, 추리 등)
- 데이터베이스(DB)에 저장 → 검색 및 분석 가능
- 사용자는 “역사 장르”, “자기계발”, “저자 이름”, “최근 추가된 책” 등 조건으로 빠르게 필터링 및 정렬 가능

## 🚀 확장 아이디어

- 결과를 CSV/Excel로 export → 개인 독서 기록 관리, 도서 목록 공유, 통계 프로그램 연동 가능
- 분류 레이블 기반 통계 대시보드 → 장르별 책 수, 최근 읽은 책 트렌드, 출판사별 비율, 표지 색상/분위기 통계 등 시각화 가능
